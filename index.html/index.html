Case Studies

Tesla Landing Page Breakdown

Problem: Recreate a clean, modern landing page inspired by Tesla while maintaining responsiveness across different screen sizes.

Decisions: Used HTML and CSS to structure and style the layout, focusing on section-based design and flexbox for alignment. Paid attention to spacing, typography, and visual hierarchy.

Learning: Improved my understanding of responsive design, layout structuring, and how small UI details affect the overall user experience.

What I'd improve: Add JavaScript for interactivity (e.g., menu toggle, animations) and optimize performance for faster load times.

UI Screenshot Project Breakdown

Problem: Recreate a given UI design as accurately as possible using code while maintaining clean structure and responsiveness.

Decisions: Focused on using HTML and CSS to match the layout, spacing, fonts, and visual hierarchy. Broke the design into smaller sections to replicate it step by step.

Learning: Improved attention to detail, layout precision, and understanding of how design translates into code.

What I'd improve: Enhance responsiveness for different screen sizes and add small interactive elements to make the UI feel more dynamic.

Project Solaris Breakdown

Problem: Many socio-economic issues in South Africa are underrepresented or lack accessible digital platforms that allow people to engage, share, and organize around them—especially across key urban centers.

Concept: Project Solaris is a social media activism platform focused on the three major capitals of South Africa, aiming to highlight issues, encourage discussion, and promote awareness through a centralized digital space.

Decisions: Designed the platform to prioritize clear content structure and user interaction. Focused on building a scalable front-end foundation first, with plans to integrate dynamic features and user-driven content.

Learning: Developing this project is improving my ability to think beyond static pages and consider real-world impact, user engagement, and how technology can support social change.

Status: Work in progress — currently focusing on core layout, content structure, and preparing for interactive features.

What I'd improve: Add user interaction features (posting, commenting), improve responsiveness, and eventually integrate a backend to support real-time data and user accounts.
